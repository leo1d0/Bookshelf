# Bookshelf

Práctica **PEA: Crea una app de Bookshelf** – Aplicaciones Móviles Nativas (ULEAM, paralelo A).
Estudiante: Leonardo David Ortiz Satizabal.

App Android en Kotlin + Jetpack Compose que busca libros en la API de Google Books
(Retrofit + Gson, Coil, repositorio, inyección de dependencias manual y ViewModel)
y muestra sus portadas en una cuadrícula.

Basada en el codelab: https://developer.android.com/codelabs/basic-android-kotlin-compose-bookshelf

La clave de API **no** está en el repositorio. Ver `CONFIGURAR_CLAVE_API.md`.
